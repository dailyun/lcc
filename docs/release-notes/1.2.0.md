# lcc 1.2.0

Draft notes for the GitHub Release. Full detail: [CHANGELOG.md](../../CHANGELOG.md#120---2026-10-19).

```sh
pip install -U "local-context-compiler[tiktoken]"
```

If you use the Claude Code plugin, update it from `/plugin` as well, so the hook and the `lcc`
it calls are both 1.2.0.

## Fixed

- **`/compact` on a long session no longer always falls back to the built-in summary.** Claude
  Code caps an MCP tool result (`MAX_MCP_OUTPUT_TOKENS`, 25,000 tokens by default on 2.1.296),
  so on any session worth compacting the plugin's request came back as a pointer text instead
  of JSON and the hook stood down. The hook now asks `compact_transcript` for `ref_blocks: true`
  and rebuilds the conversation from the session's own messages. A capped answer now says so in
  the toast instead of showing a JSON parse error.
- **`recoverable` and `stashed` now accept whole-file reads of newline-terminated files.**
  Claude Code 2.1.296 numbers the empty line after a file's final newline, so these reads always
  failed the disk check (`keep_disk_mismatch`) and were never replaced or stashed.

## Added

- **Idle stash for the Claude Code plugin (opt-in, off by default).** With `idleStash: true`, a
  session you resume after `idleTtlSeconds` (default 7200) of idle has its spent tool outputs
  stashed before the first request re-writes an already expired prompt cache. Stashed outputs
  stay recoverable with `recall`. Every failure skips; it never falls through to the built-in
  summary. It runs only on resumed interactive sessions, not on a session left open and not in
  `-p`/SDK sessions. Evidence (INFERIDO) and limits:
  [CLAUDE_CODE.md](../CLAUDE_CODE.md#idle-stash-opt-in).
- **`compact_transcript` options `ref_unchanged` and `ref_blocks`.** They return unchanged
  messages and blocks as references to the input instead of resending them, which keeps
  answers under Claude Code's MCP result cap. On a synthetic 1 MB transcript the answer went
  from 1.5 MB to 10.6 KB (`ref_unchanged`) and 2.1 KB (`ref_blocks`).

## Upgrade notes

- No breaking changes. `/compact` behaviour is unchanged apart from the fix above.
- The plugin still needs Claude Code 2.1.274+ and `CLAUDE_CODE_ENABLE_FUNCTION_HOOKS=1`.
- To try the idle stash, set `idleStash: true` and allow `mcp__plugin_lcc_lcc__recall` so the
  agent can get stashed outputs back.
